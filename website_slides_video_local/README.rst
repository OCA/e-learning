Add a self-hosted video source to eLearning lessons, next to the
YouTube, Google Drive and Vimeo sources Odoo ships.

Use it when a course video has to stay on the Odoo server: there is no
third-party video account, or the recording cannot leave the host. The
file is a normal attachment and is streamed with HTTP Range requests, so
learners can seek. An optional WebVTT file is shown as a caption track.

Usage
=====

On a lesson whose content type is Video, set Source to *Upload from
Device* and upload the video file. The video link is not required once a
file is set. The lesson plays in the browser's video player, including
the fullscreen player.

Optional captions go in *Captions (WebVTT)* on the same lesson. A lesson
without captions still loads an empty track, so the player does not
report a missing file.

The website "Add Content" dialog still asks for a video URL. Upload the
file from the lesson form in the backend.
